# 🚀 XMR Nexus

**XMR Nexus** è una dashboard moderna e un proxy manager per il mining di Monero (XMR).  
Il progetto permette agli utenti di:
- Monitorare hash rate e worker in tempo reale
- Selezionare il pool preferito direttamente dalla dashboard
- Scaricare un pacchetto miner preconfigurato
- Gestire il mining in modo semplice e centralizzato
